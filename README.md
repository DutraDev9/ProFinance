# Pro Finance Control

Aplicativo de controle financeiro em React + Vite + Tailwind CSS integrado ao Firebase (`pro-finance-control`).

## Como rodar localmente

1. Extraia o arquivo `.zip`
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
